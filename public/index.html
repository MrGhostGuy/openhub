Game Auto-Improvements

What this does

Point an agent at one of your games and it will audit it for real defects, fix them, add mechanics that make it feel like the original, prove every claim with tests, and push a live build. Try: "auto-improve minimon".

How the agent works

1. Verify live deploy for console errors; every reachable screen must actually render.
2. Audit for features the code claims but never wires up — that is where the real bugs hide.
3. Fix in impact order: crashes, soft-locks, broken persistence, exploits.
4. Add authentic mechanics so it plays like the original.
5. Prove with unit tests against real data plus a live browser run.
6. Ship and report honestly, including what was not fixed.
